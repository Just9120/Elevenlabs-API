### Эпик `RESULTS-STUDIO-02` — Live-результат и временное восстановление обычного экспорта

| AC | Проверяемое требование |
|---|---|
| `RS-01` | Владелец читает сохранённый Live-текст с абзацами, доступными метками спикеров и метаданными; редактирование текста и имён не требуется. Проверка: committed/partial display, восстановление и owner isolation. Q126,Q127. |
| `RS-02` | Сохранённый Live-текст скачивается как DOCX со стандартом transcript_doc. Проверка: DOCX structure/header/paragraph/speaker formatting без нового STT. Q134,Q138..140. |
| `RS-03` | Владелец явно очищает Live-текст из local и server recovery, не удаляя внешние документы. Проверка: clear/reload/concurrent save, чужой owner и повторный delete. Q120,Q126,Q165. |
| `RS-04` | **SUPERSEDED, вне denominator → PB-06, PR-04.** Q125/Q128/Q129: cloud-free текст относится к Live, обычный результат — внешний документ. Сохранённая формулировка: Device batch работает без облачного подключения и без целевой облачной папки. Основание: S031,S032,S122. |
| `RS-05` | Обычная задача отдельно отражает STT и создание документа; пустой/частичный документ не становится completed. Проверка: STT success/export failure/partial write/reconciliation. Q129,Q130. |
| `RS-06` | При ошибке создания обычного документа доступный STT текст переживает restart и хранится до полного export либо явной отмены; автоматический срок удаления не заменяет решение владельца. Проверка: restart и задержанный export >24 h без нового STT. Q131. |
| `RS-07` | **ALIAS, вне denominator → PR-05, PR-11.** Скачивание сохранённого Live TXT без нового STT по Q126/Q134 уже покрыто current/recovered actions; не считать повторно. Прежний ID сохранён, отменённый batch TXT не возвращается. |
| `RS-08` | Повтор незавершённой выгрузки использует доступный готовый STT текст без нового provider call и без дополнительного подтверждения расхода; явная отмена завершает восстановление. Проверка: complete cached recovery, partial cache, expiry, export failure/cancel. Q131,Q132. |
| `RS-09` | **ALIAS, вне denominator → PR-05.** Скачивание сохранённого Live TXT без нового STT по Q126/Q134 уже покрыто current/recovered actions; не считать повторно. Прежний ID сохранён, отменённый batch TXT не возвращается. |
| `RS-10` | Таймкоды Live SRT/VTT соответствуют аудио/сессии, для которой подготовлен результат; обработанная версия не подменяется исходной. Проверка: timed segments, gap/correction и преобразованный source. Q135,Q136. |
| `RS-11` | Без необходимых временных данных SRT/VTT не предлагаются как корректный timed export; пользователь получает понятное объяснение ограничения. Проверка: timed/untimed states и aria feedback. Q137. |
| `RS-12` | **SUPERSEDED, вне denominator → PM-05.** Q146/Q150: success только полный документ, без обещания восстановления утраченного внешнего документа. Сохранённая формулировка: Манифест различает сохранённое распознавание и облачный экспорт; потеря облачного файла не требует нового STT. Основание: S138,S141. |
| `RS-13` | Владелец сохраняет JSON snapshot манифеста в выбранную папку Google Drive; отмена выбора ничего не записывает, повтор неизменённого snapshot не создаёт дубликат в той же папке, ошибки не очищают учёт Studio. Snapshot содержит metadata без текста и secrets. Проверка: owner/CSRF, reset cutoff, folder access, fake transport, cancel/repeat/error UI. Основание: Q148/S140. |
| `RS-14` | **SUPERSEDED, вне denominator → RS-06, PR-09.** Q125/Q131: постоянная обычная копия в S3 исключена; Live и transient text отдельны. Сохранённая формулировка: Полная сохранённая транскрипция размещается во внутреннем S3 своего окружения. Основание: S152. |
| `RS-15` | **SUPERSEDED, вне denominator → PR-12, STORAG-06.** Q118/Q162: 3/7/30 относится к device source, Live без TTL. Сохранённая формулировка: Для сохранённой транскрипции выбирается общий срок 3, 7 или 30 дней и видна дата удаления. Основание: S153,S154. |
| `RS-16` | **SUPERSEDED, вне denominator → PC-10, PR-12.** Q118/Q164: expiry источника не expiry Live. Сохранённая формулировка: Expired transcript недоступен для просмотра и скачивания, включая старые ссылки. Основание: S155,S169. |
| `RS-17` | **SUPERSEDED, вне denominator → RS-03, STORAG-15.** Q165/Q170/Q174: очистка текста/исходников разделена. Сохранённая формулировка: Удаление внутреннего результата подтверждается фактическим cleanup и не удаляет пользовательский облачный экспорт. Основание: S159,S165. |

Проверка AC этого эпика: Unit/component/contract проверки позитивного и негативного сценария, owner isolation и повторов; browser проверяет пользовательский результат; внешние side effects и recovery — отдельный разрешённый сценарий точной версии.
